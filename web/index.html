      Despesas por semana

      Semanas de segunda a domingo. Nas semanas que cruzam o filtro, soma somente os lançamentos dentro do período consultado.

        Ajustes anuais de taxas

        Todos os anos cadastrados, independentemente do filtro. Valores estimados continuam identificados.

          Nova venda

          Informe o cartão antes das taxas. Campos vazios valem zero. Cada data pode ter apenas um registro.

          Nova despesa

          Para parcelar, escolha Cartão de crédito. O valor é de cada parcela. A data é o primeiro vencimento; os próximos serão mensais. Um compromisso já lançado não deve ser cadastrado de novo como parte da fatura.

          Ajuste anual de taxas

          Use o valor total das taxas do intervalo, sem somar taxas diárias já cadastradas na mesma cobertura. O ajuste só é descontado quando o filtro inclui todo o intervalo.
